MoneyCalc Pro v6 - adaptive bundle
Developer: Hazem Salah
Features: dashboard-first, dot-style charts, reminders (default 28), optional fields (hours, patients, echos), backup (asks where to save), CSV export, offline PWA.
Instructions:
- Unzip and open index.html in Chrome on your phone. Use Chrome menu > Add to Home screen to create an icon.
- Backup: tap Backup -> choose where to save the JSON file (browser will ask).
